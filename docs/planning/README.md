# Christmas Gift For You

크리스마스에 마음을 전하는 웹 서비스. 캐롤이 흐르는 페이지에서 두 가지 공간을 쓴다.

- **공개 트리:** 홈의 큰 트리 하나에 누구나 직접 꾸민 카드(편지)를 프로필과 함께 건다. 거는 즉시 모두가 읽고 좋아요를 누를 수 있다. 지인이 적거나 새 인연을 원하는 사람을 위한 광장.
- **비공개 그룹:** 한 명이 만들고 링크로 초대. 멤버끼리 선물상자(편지·사진·음반)를 지정하거나 마니또로 랜덤하게 보낸다. **12/25 12:25에 한꺼번에 열린다.** 지인끼리 조용히 즐기는 방.

- 운영: 2026-12-21 공개 → 12/24 23:59 마감 → 12/25 12:25 개봉 (카카오톡 알림) → 2027-01-31 파기
- 팀: FE 1, PM 1(백엔드는 FE와 유동 분담), 디자이너 1(시안·에셋)
- 서버: Supabase Cloud 무료 요금제로 시작, 12/15 QA 결과로 부족하면 동아리 서버(server2) → 개인 미니 PC로 이전
