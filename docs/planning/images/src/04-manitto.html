마니또 추첨 (마니또 3개: 서준·민지·지호가 보냄)

순서(시드 고정)보낸 사람후보 = 본인·지정 보낸 멤버 제외받은 수 최소결과
1서준민지 하은 지호 유나 (서준 → 민지 지정 ✕) → 하은 지호 유나하은 0, 지호 0하은 (동률 → 난수)
2민지서준 하은 지호 유나 (민지 → 유나 지정 ✕) → 서준 하은 지호서준 0, 지호 0지호 (동률 → 난수)
3지호민지 서준 하은 유나 (지호 → 민지 지정 ✕) → 서준 하은 유나서준 0서준
결과: 5명 모두 1개 이상 받음
· 시드 고정 + 결과 저장 → 다시 돌려도 같은 결과
· 후보가 없으면 미전달 → 보낸 사람에게 안내
· 개봉 때 "🎁 마니또는 ○○님이었어요"
