# Christmas Gift For You — 기능 명세서

> 문서 체계: `design.md` > `정책명세서.md`(이하 "정책") > `기능명세서.md` / 일정은 `개발운영계획.md`.
> 모바일 웹. **우선순위:** P0 = 없으면 서비스 불가, P1 = 개봉 경험에 필요, P2 = 있으면 좋음.
> **표기:** 확정 = PM 결정 / 제안 = 결정 전 기본안. 기준일 2026-11-24.

## 화면 흐름

```
⓪ 홈(공개 트리) ─┬─ 카드 탭 → ③ 카드 보기 (좋아요·신고)
                 ├─ [전체 보기] → ④ 카드 목록
                 ├─ [카드 걸기] → (①②) → ② 카드 꾸미기 → ⓪
                 └─ [내 그룹] → ⑩ 마이페이지

/g/{code} → ⑥ 초대 랜딩 → (①②) → ⑦ 그룹 홈 ─┬─ [선물 보내기] → ⑧ 선물상자 꾸미기 → ⑦
                                              └─ 12/25 12:25~ → ⑨ 개봉
[그룹 만들기] (⓪·⑩) → ⑤ 그룹 만들기 → ⑦
                       └─ '모두 마니또' 켬 → ⑧ 참여 모드 → ⑦
/g/{code} (옵션 그룹) → ⑥ 초대 랜딩 → (①②) → ⑧ 참여 모드 → ⑦
```
