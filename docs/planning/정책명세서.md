## 1. 용어

| 용어 | 정의 |
|---|---|
| 공개 트리 | 홈에 있는 서비스 전체 공용 트리 1개 |
| 카드 | 공개 트리에 거는 것. 꾸민 겉모습 + 편지 + 작성자 프로필 |
| 그룹 | 한 사용자가 만든 비공개 공간. 초대 링크로 참여 |
| 선물상자 | 그룹 안에서 보내는 선물. 겉(색·스티커) + 속(편지·사진·음반) |
| 지정 선물 | 보내는 사람이 받을 멤버를 고른 선물상자 |
| 마니또 선물 | 받는 사람을 마감 후 추첨하는 선물상자. 개봉 때 보낸 사람 공개 |
| 음반 | 선물상자 속 구성품. 상자당 최대 1개, 표지 + YouTube 링크 1곡 |
| 배경 캐롤 | 모든 화면에 흐르는 저작권 문제없는 캐롤 음원 |

## 3. 공개 트리

### 3.1 카드
- 로그인 필요. **1인 1장** `[제안]`. 걸기·수정·삭제 모두 12/25 23:59까지.
- 구성 `[확정]`: **카드(앞면) + 편지(뒷면)**. 앞면은 ① 기본 카드 이미지 중 하나 고르기 또는 ② 직접 그리기 중 하나에, 스티커를 붙인다. 선물상자 꾸미기를 축소한 형태.
  - 직접 그리기: 펜 굵기 2~3종, 색 8종, 지우개, 되돌리기 `[제안]`. 결과는 이미지(PNG)로 저장.
  - 스티커 최대 20 `[제안]`.
  - 편지 300자 `[제안]`, 빈 값 불가.
- 직접 그린 그림도 거는 즉시 공개된다. 검수는 프로필 사진과 같이 신고 → 운영자 확인(자동 숨김 없음).
- **사진·음반 없음** `[제안]`: 즉시 공개되는 사진은 검수 부담이 크고, 트리 카드는 가볍게 많이 걸리는 것이 목적.
- 카드에는 작성자 프로필 사진이 **작은 아이콘**으로 붙는다(트리 장식·카드 보기·목록 모두). 아이콘을 누르면 작성자 프로필(큰 사진·닉네임)을 볼 수 있다 `[확정]`. 프로필에 그룹 정보는 보이지 않는다 `[제안]`.
- 거는 즉시 누구나 전체 내용 열람 `[확정]`. 비로그인 열람 허용 `[제안]`.

### 3.2 좋아요 `[확정: 좋아요]`
- 로그인 필요. **한 사람이 한 카드에 1번** `[확정]`, 다시 누르면 취소 `[제안]`. **좋아요를 누를 수 있는 카드 수는 제한 없음** `[확정]`. 본인 카드에도 가능 `[제안]`.
- 좋아요 수(= 누른 사람 수)는 모두에게, **누른 사람 목록은 카드 작성자에게만** `[확정]`.
- **반짝임** `[확정: 5개 이상]`: 좋아요 5 이상인 카드는 트리 전체 화면에서 반짝인다. 많을수록 밝게: 5~19 약하게, 20~49 중간, 50 이상 강하게 `[제안: 단계]`.
- 댓글·DM 없음 `[제안]`.

### 3.3 트리 표시
- 트리 장식 칸 50개 `[제안: 칸 수]`: **숨김 아닌 카드 중 전부 무작위** `[확정]`. 트리를 열 때마다 다시 뽑는다. 내 카드는 내 화면에서 항상 보이게 고정 `[제안]`.
- 카드를 열면 양옆 화살표로 다음·이전 카드로 넘긴다 `[확정]`. 순서는 무작위(한 번 본 카드는 그 둘러보기 안에서 다시 나오지 않음) `[제안]`.
- 전체 카드는 목록에서 무작위(기본)/좋아요순/최신순.
- 숨김 처리된 카드는 트리·목록에서 빠지고 작성자에게만 "숨겨진 카드" 표시.

## 4. 비공개 그룹

### 4.1 생성·참여 `[제안: 수치]`
- 로그인한 누구나 생성, 개수 제한 없음 `[확정]`. 그룹 이름 20자.
- **만든 사람과 참여한 사람의 권한 차이 없음** `[확정]`. 만든 사람도 그냥 멤버.
- 초대 링크 `/g/{code}`(추측 불가 코드). 링크로 들어와 로그인 → [참여하기].
- **정원 30명**, 참여는 12/24 23:59까지. 한 사람이 여러 그룹 가능.
- 나가기·강퇴 없음(탈퇴 기능 없음과 같은 이유: 이미 받은 선물 처리 복잡). 문제 사용자는 신고 → 운영자 처리.
- **'모두 마니또' 옵션** `[확정 11/25]`: 그룹을 만들 때만 켜고 이후 변경 불가, 기본값 꺼짐. 켜진 그룹은 만든 사람을 포함해 **마니또 상자 1개를 만들어야 참여(생성)가 끝난다.** 상자 저장과 멤버 추가는 한 번에 처리되고, 정원·마감은 꾸미기 전과 저장 순간에 두 번 검사한다. 초대 랜딩에 "이 그룹은 랜덤 선물 1개를 준비해야 들어갈 수 있어요"를 안내한다.

### 4.2 열람 범위 (개봉 전)
- 그룹 홈 `[디자인 미확정]`: 메인 구조물(트리 + 내가 받은 상자 겉모습), 멤버별 요정(프로필 사진), D-n. **받은 수·못 받은·안 보낸 멤버 숫자는 보여주지 않는다** `[확정]`.
- 받는 사람은 개봉 전 **내가 받은 상자의 겉모습(색·스티커)**만 본다 `[확정]`. 보낸 사람(지정 포함)과 속(편지·사진·음반)은 12/25 12:25까지 잠김 `[제안: 지정 선물 보낸 사람도 개봉 때 공개]`. 마니또 상자는 추첨 직후(추첨은 12/25 01:00까지) 겉모습만 더해진다.
- 다른 멤버가 받은 상자는 숫자로 보여주지 않는다 `[확정]`. 산타 버전은 그 멤버 집 트리 아래 상자 그림으로만 보일 수 있다 `[디자인 미확정]`. 속은 보낸 사람 본인만 볼 수 있다.
- 그룹 밖 사람은 그룹 이름·멤버를 볼 수 없다. 초대 랜딩에서는 그룹 이름과 멤버 수만.

## 5. 선물상자

### 5.1 보내기 `[확정: 지정·마니또]`
| 방식 | 대상 | 한도 `[제안]` |
|---|---|---|
| 지정 | 같은 그룹의 다른 멤버 1명 | 받는 사람 1명당 1개 |
| 마니또 | 마감 후 추첨(§5.3) | 그룹마다 1인 1개 |

- 자기 자신에게 보낼 수 없다.
- 마감 전까지 수정·취소.
- '모두 마니또' 옵션 그룹: 마니또 상자는 참여 조건이라 **취소·방식 변경 불가, 수정만** `[제안]`. 지정 선물은 옵션과 상관없이 그대로.
- 마감 전 넛지 `[제안]`: 12/24 18:00 ~ 23:59, 그 그룹에 상자를 하나도 안 만든 멤버 **본인에게만** 그룹 홈 배너 "아직 보낼 수 있어요". 다른 멤버에게는 보이지 않고 숫자도 없다.

### 5.2 구성
| 구성 | 규칙 |
|---|---|
| 겉 | 상자·리본 색, 스티커 최대 20 (눌러서 정해진 자리, 끌기·크기 조절은 P2) |
| 편지 | 500자 `[제안]`. 금칙어 검사 없음 `[확정 11/24]` |
| 사진 | 최대 5장, jpg/png, 장당 5MB, EXIF 제거, **업로드 전 브라우저에서 긴 변 1600px로 줄여 저장** `[확정 11/24]`, 비공개 저장, 서명 URL |
| 음반 | §6 |

- 속 구성(편지·사진·음반) 중 하나 이상 필수.
- 옵션 그룹 참여 모드(참여 전에 만드는 첫 상자): 받는 사람은 마니또로 고정, **사진 제외**(편지·음반·색·스티커). 사진은 참여 후 수정에서 추가 `[제안]`.
- 마니또 선택 시 안내: "그룹 안 누구에게 갈지 몰라요. 모두가 봐도 괜찮은 사진만 넣어 주세요" `[제안]`.
- 고지: "결제 없음 · 사진만 전달 · 기프티콘 사용 여부 비보증".

### 5.3 마니또 추첨 `[제안: 알고리즘]` (상세: `design.md` §7)
- 마감 직후 그룹마다 실행. 후보 = 보낸 사람과 **보낸 사람이 이미 지정 선물을 보낸 멤버를 제외**한 멤버 `[확정]` (한 사람의 선물이 같은 사람에게 두 번 가지 않게).
- 후보 중 **받은 선물이 가장 적은 멤버**를 우선, 동률은 시드 고정 난수.
- 결과 저장, 재실행해도 불변. 후보가 없으면 미전달.
- '모두 마니또' 옵션 그룹 `[제안]`: 모두 정확히 1개씩 주고받는 짝 맞추기(같은 제외 규칙, 시드 고정). 완전한 짝이 불가능할 때만 위 방식으로 처리.

### 5.4 개봉
- 12/25 12:25, 받은 상자 전부 열람 가능.
- 지정 선물: 보낸 사람 닉네임 표시. 마니또 선물: 열 때 "🎁 마니또는 ○○님이었어요" `[확정]`.
- 답장: 상자마다 "고마워요" 한 줄 1회, 50자 `[제안]`, **12/31 23:59까지** `[확정 11/25]` → 보낸 사람의 보낸 선물 화면에 도착.
- 미전달 마니또: 보낸 사람에게 "받을 멤버가 없어 전달되지 않았어요".

## 6. 음악

### 6.1 배경 캐롤 `[확정: 저작권 없는 캐롤 배경 재생]`
- CC0·퍼블릭 도메인 녹음, 또는 CC BY(크레딧 표기)만 사용 `[제안]`. 곡 자체가 퍼블릭 도메인이어도 녹음 라이선스를 따로 확인.
- 5~10곡 자체 저장소, 순환 재생. 출처·라이선스는 크레딧 페이지.
- 첫 사용자 탭 이후 재생(자동재생 정책). 켜기/끄기 버튼, 선택은 기기에 기억 `[제안]`.
- YouTube 임베드(음반) 재생 중 자동 일시정지 `[확정]`.

### 6.2 음반 `[확정: YouTube 링크 붙여넣기]`
- 입력: youtube.com / youtu.be / music.youtube.com 링크만. oEmbed로 제목·썸네일 확인, 실패(비공개·삭제·퍼가기 금지)면 거부. **YouTube Data API(검색)는 쓰지 않는다.**
- **상자당 음반 최대 1개, 음반 1개 = YouTube 링크 1곡** `[확정]`. 표지 색 + 제목(20자).
- 작성 중 미리듣기 허용. 받는 사람은 개봉 후 재생.
- 재생: 페이지 안 YouTube 공식 임베드. 광고 음소거·가리기·자동 스킵 금지. 음원 추출·저장 금지.
- 첫 재생 전 "광고가 나올 수 있어요" 안내.

## 7. 계정·프로필 `[확정: 로그인 유지]`

- 카카오·구글 OAuth. 공개 트리 열람·초대 랜딩 열람은 비로그인 허용, 그 외 쓰기는 로그인 필요.
- 첫 가입: 닉네임(12자, 공백만 불가, 금칙어·연락처 차단, 중복 허용), **프로필 사진은 사용자가 선택** `[확정]`: 직접 사진을 올리거나, 올리지 않으면 기본 프로필 이미지. jpg/png 5MB, EXIF 제거, 정사각형으로 줄여 저장. 공개 트리에서 모두에게 보이므로 업로드 화면에 "모든 사람에게 보여요" 안내.
- 개인정보 수집·이용 동의(필수), 만 14세 이상 확인(필수).
- 탈퇴 기능 없음. 삭제 요청은 처리방침 문의 이메일로 수동 처리(닉네임·카드·편지·사진 삭제).

### 7.1 12/25 개봉 알림 `[확정: 수단 유지]`
- 카카오톡 "나에게 보내기", 12/25 12:25 일괄. 동의한 사용자만, 사람당 1통.
- 내용: 그룹 멤버면 "🎁 크리스마스 선물이 열렸어요", 아니면 "🎄 트리에 불이 켜졌어요" + 링크 `[제안]`.
- 구글 로그인 사용자는 [카톡으로 개봉 알림 받기]로 카카오 동의만 추가.
- `[확인 필요]` 메시지 동의항목 조건(비즈앱 여부), 예약 발송·발송량 제한, refresh token 수명. 관문 1(11/25, 실제 토큰 실발송 스파이크로 판정).

## 8. 안전·신고 `[제안]`

| 대상 | 신고 가능 시점 | 처리 |
|---|---|---|
| 공개 카드 | 상시 | **자동 숨김 없음** `[확정]`. 운영자가 신고 목록을 보고 직접 숨김 |
| 닉네임·프로필 사진 | 상시 (카드 보기·작성자 프로필·그룹 요정 창에서) | 운영자 확인 후 기본값으로 초기화 |
| 선물(편지·사진·음반) | 개봉 후, 받은 사람만 | 운영자 확인 후 숨김 |

- 그룹 이름은 초대받은 지인끼리만 보이므로 별도 신고 없음, 문의 이메일로 처리.

- 저장 전 금칙어·전화번호·URL 패턴 검사는 **공개 트리에 보이는 글(카드 편지·닉네임)에만** 한다 `[확정 11/24]`. 비공개 그룹은 지인끼리 쓰는 공간이라 그룹 이름·선물 편지·답장·음반 제목은 검사하지 않는다. 신고는 그대로 받는다.
- 공개 트리는 운영 기간 내내 열려 있으므로 **12/21부터 신고 확인 당번**이 필요(하루 2회, `개발운영계획.md` §7).
- 쓰기 요청 수 제한 `[확정 11/25]`: 카드·선물 저장(수정·업로드 포함) 1인 분당 10회, 신고 1인 하루 20회.
