# FE-03 프로필 설정 (첫 가입)

- 주차: 1주차 (11/27) · 우선순위: P0 · 화면: ①-a · 계획: F3
- 근거: 요구사항 4.2절, 기술 4.4절
- 선행: FE-02, BE-01 · 이 작업을 쓰는 작업: FE-12(프로필 수정 재사용)

## 목적

첫 로그인 후 닉네임, 프로필 사진, 필수 동의, 카톡 알림 여부를 받는다.

## 화면과 동작 (①-a)

- 제목 "프로필 설정", 설명 "트리와 그룹에서 이렇게 보여요".
- 프로필 사진: "사진 올리기"(긴 변 512px JPEG로 줄여 `avatars/{내 id}/{uuid}.jpg`에 업로드) 또는 "건너뛰기(기본 이미지)". 안내 "닉네임과 프로필 사진은 모든 사람에게 보여요".
- 닉네임: 입력란 + 카운터 `n/12`. 안내 "최대 12자 · 나중에 마이페이지에서 바꿀 수 있어요".
- 필수 동의 2개: "[필수] 개인정보 수집·이용 동의"(보기 링크), "[필수] 만 14세 이상이에요".
- 토글 "카톡으로 개봉 알림 받기", 설명 "12/25 12:25 선물이 열리면 알려드려요".
  - 카카오 로그인 사용자: 기본 켜짐.
  - 구글 로그인 사용자: 꺼짐·비활성, 안내 "카카오 로그인 사용자만 받을 수 있어요".
- "시작하기"는 닉네임이 유효하고 두 동의가 모두 체크됐을 때만 누를 수 있다.
- 하단 "모든 데이터는 2027-01-31에 삭제돼요".
- 저장 후 로그인 전에 가려던 곳(없으면 `/`)으로 간다.
- 토글을 켰는데 `kakaoMessageConsent === false`(로그인 때 메시지 동의를 거부)이면, 저장 후 카카오 로그인을 다시 실행해 동의 화면을 띄운다.

## 사용하는 백엔드

- `rpc('complete_profile', { p_nickname, p_avatar_path, p_kakao_notify })` (BE-01)
- Storage `avatars`

## 예외 처리

- `profile_exists` → 무시하고 다음 화면으로.
- 업로드 실패 → "사진을 올리지 못했어요. 다시 시도하거나 건너뛰어 주세요".

## 만드는 것

- `resizeImage(file: File, maxEdge: number): Promise<Blob>` (JPEG, 품질 0.85. FE-10도 쓴다)
- `validateNickname(raw: string): 'empty' | 'too_long' | null` (앞뒤 공백 제거 후)

## 완료 조건

Vitest:
- [ ] `validateNickname`: `""`·`"   "` → `empty`, `"눈사람조아"` → `null`, 12자 → `null`, 13자 → `too_long`, 이모지 12개 → `null`

직접 확인:
- [ ] 새 계정으로 마치면 `profiles`·`user_settings`에 각 1행, 사진을 올렸다면 `avatars`에 파일 1개.
- [ ] 같은 계정으로 다시 로그인하면 이 화면을 건너뛴다.
- [ ] 구글 계정에서는 토글을 켤 수 없다.
