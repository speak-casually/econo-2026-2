# FE-07 그룹 만들기·초대 링크 공유

- 주차: 2주차 (11/30) · 우선순위: P0 (카카오톡 공유는 P1) · 화면: ⑤
- 근거: 요구사항 6.1·6.3절
- 선행: FE-02, BE-06, BE-08 · 이 작업을 쓰는 작업: FE-09(초대하기), FE-12(그룹 만들기 버튼)

## 목적

비공개 그룹을 만들고, 만든 즉시 초대 링크를 공유한다.

## 화면과 동작 (⑤, `/groups/new`, 로그인·프로필 필요)

- 제목 "비공개 그룹 만들기", 설명 "초대받은 친구들끼리만 선물을 주고받아요".
- 그룹 이름 입력 + 카운터 `n/20`.
- 토글 "모두 마니또". 설명 "켜면 모든 멤버가 마니또 선물을 1개씩 만들어야 들어올 수 있어요. 만든 뒤에는 바꿀 수 없어요".
- 안내: "12/25 12:25에 모든 선물이 함께 열려요", "최대 30명 · 만든 사람도 일반 멤버예요".
- "만들기"
  - 모두 마니또 꺼짐: `create_group(이름, false)`.
  - 모두 마니또 켜짐: 선물상자 꾸미기(FE-10)를 **입장 모드**로 열어 내 마니또 선물을 먼저 만들고, 그 결과로 `create_group(이름, true, 상자)`.
- 성공하면 초대 시트가 올라온다.
  - "🎉 그룹이 만들어졌어요!", "초대 링크를 공유해서 친구들을 불러요"
  - 링크 `<origin>/g/{invite_code}`와 "복사" 버튼
  - "링크 복사", "카카오톡"(Kakao JS SDK 공유), "더보기"(`navigator.share`, 없으면 복사)
  - "나중에 할게요" → 그룹 홈
- 마감 후에는 이 화면 대신 "그룹 만들기가 마감됐어요".

## 초대 시트 재사용

같은 시트를 그룹 홈의 "초대하기"(FE-09)에서도 쓴다: `<InviteSheet code groupName />`.

## 사용하는 백엔드

- `rpc('create_group', { p_name, p_all_manito, p_manito_box })` (BE-06, BE-08)

## 예외 처리

- `deadline_passed` → "마감됐어요". 모두 마니또 상자 관련 에러(`empty_contents`, `invalid_photo_path`)는 FE-10 입장 모드에서 문구를 보여주고 상자 화면에 머문다.

## 완료 조건

- [ ] Vitest: `inviteUrl(origin, code)`가 `https://a.vercel.app/g/ab12cd34` 형식을 만든다.
- [ ] 직접 확인: 일반 그룹을 만들면 그룹 홈에 나 혼자 있다. 모두 마니또 그룹을 만들면 내 마니또 상자도 함께 생긴다. 상자 만들기를 취소하면 그룹이 생기지 않는다.
- [ ] 카카오톡 공유로 받은 메시지를 누르면 초대 랜딩이 열린다.
