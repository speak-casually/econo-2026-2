# FE-08 초대 랜딩·참여

- 주차: 2주차 (11/30) · 우선순위: P0 · 화면: ⑥
- 근거: 요구사항 6.2·6.3절
- 선행: FE-02, BE-06, BE-08 · 이 작업을 쓰는 작업: 없음

## 목적

초대 링크로 들어온 사람이 그룹 정보를 보고 참여한다.

## 화면과 동작 (⑥, `/g/:code`, 보기는 비로그인 가능)

- 초대장 카드: "[{그룹 이름}]에 초대받았어요", "멤버 {N}명", "12/25 12:25에 선물이 열려요". **멤버 이름은 보여주지 않는다.**
- 모두 마니또 그룹이면 안내 "이 그룹은 모두 마니또예요. 마니또 선물을 1개 만들어야 들어갈 수 있어요".
- 하단 "참여하기"
  - 비로그인 → `/login?returnTo=/g/{code}`.
  - 이미 멤버 → 바로 그룹 홈.
  - 일반 그룹 → `join_group(code)` → 그룹 홈.
  - 모두 마니또 그룹 → 선물상자 꾸미기(FE-10) 입장 모드 → 결과로 `join_group(code, 상자)` → 그룹 홈.
- 페이지를 열었을 때 이미 멤버면(로그인 상태) 바로 그룹 홈으로 보낸다.
- 마감 후: 버튼 대신 "참여가 마감됐어요".
- 없는 코드: "초대 링크를 찾을 수 없어요"와 홈 버튼.
- 카톡 인앱에서 열려도 초대장은 보인다. 로그인 단계에서 FE-02의 외부 브라우저 안내가 나온다.

## 사용하는 백엔드

- `rpc('get_invite', { p_code })`, `rpc('join_group', { p_code, p_manito_box })` (BE-06, BE-08)

## 예외 처리

| 코드 | 문구 |
|---|---|
| `group_full` | "정원이 다 찼어요" |
| `deadline_passed` | "참여가 마감됐어요" |
| `invite_not_found` | "초대 링크를 찾을 수 없어요" |
| `manito_box_required`, `empty_contents` | 상자 화면에 머물며 "마니또 선물을 먼저 만들어 주세요" / "편지, 사진, 음반 중 하나는 넣어 주세요" |

## 완료 조건

직접 확인:
- [ ] 시크릿 창에서 초대 링크를 열면 이름과 멤버 수만 보인다.
- [ ] 로그인 후 원래 초대 화면으로 돌아오고, 참여하면 그룹 홈으로 간다.
- [ ] 이미 멤버가 링크를 다시 열면 바로 그룹 홈으로 간다.
- [ ] 모두 마니또 그룹은 상자를 만들기 전에는 들어갈 수 없다.
- [ ] 정원이 찬 그룹은 "정원이 다 찼어요".
