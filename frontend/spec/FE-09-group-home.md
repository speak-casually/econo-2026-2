# FE-09 그룹 홈·집 내부

- 주차: 2주차 (12/1) · 우선순위: P0 (썰매·요정 연출 P1) · 화면: ⑦, ⑦-E
- 근거: 요구사항 6.4·6.5·8.2절(미전달)
- 선행: FE-07, BE-06, BE-07, BE-10 · 이 작업을 쓰는 작업: FE-10, FE-11, FE-16

## 목적

그룹 멤버가 서로의 집을 둘러보고, 선물을 놓으러 간다. 받은 개수는 숫자로 보여주지 않는다.

## 그룹 홈 (⑦, `/groups/:groupId`, 멤버만)

- 멤버가 아니면 "이 그룹의 멤버가 아니에요"와 홈 버튼.
- 상단: 그룹 이름 ▾(내 그룹 사이 전환), 칩 "D-{n} · 12/25 12:25 개봉".
- 본문: 멤버마다 집이 하나씩 있는 지도. 집 아래 닉네임, 내 집은 "내 집". 디자이너가 정한 버전(산타: 하늘 지도, 썰매 시점·드래그로 둘러보기 / 요정)으로 그린다. 멤버 수만큼 지도가 넓어진다.
- "목록 보기": 멤버 목록 시트(아이콘·닉네임, 누르면 그 집으로).
- 하단 버튼: "🎁 마니또 선물 보내기"(이 그룹에 내 마니또가 없으면 새로, 있으면 수정), "초대하기"(FE-07의 초대 시트).
- 추첨 후(`draws` 행이 있음) 내 마니또 상자가 미전달이면 배너 "받을 사람이 없어 전달되지 않았어요".
- 개봉 시각 이후에는 "선물 열기" 버튼 → `/groups/:groupId/open`.
- 마감 후에는 선물 버튼과 초대하기를 숨긴다.

## 집 내부 (⑦-E, `/groups/:groupId/members/:userId`, 멤버만)

- 제목 "{닉네임}님의 집". 내 집이면 "내 집".
- 트리 아래에 그 멤버가 받은 상자들을 **겉모습 그림으로만** 늘어놓는다. 개수 숫자는 없다.
- 안내 "보낸 사람·속은 12/25 12:25까지 잠겨 있어요".
- 버튼(다른 멤버의 집, 마감 전)
  - 이 그룹에서 이 멤버에게 지정 선물을 보낸 적 없음 → "선물 상자 만들기" → `/groups/:groupId/gifts/new?to={userId}`.
  - 이미 보냄 → "이미 선물을 놓았어요 · 수정하기" → `/groups/:groupId/gifts/{boxId}/edit`.
- 내 집에는 버튼이 없다.
- 그룹 홈에서 집을 누르면 썰매가 0.8초 동안 이동한 뒤 들어간다(P1, 탭하면 건너뛴다).

## 상단 바 "내 그룹" 동작 (FE-01의 버튼)

- 비로그인 → 로그인. 그룹 0개 → `/groups/new`. 1개 → 그 그룹 홈. 2개 이상 → `/me`의 내 그룹 목록.

## 사용하는 백엔드

- `groups`, `group_members` + `profiles`, `gift_boxes`(겉), `gift_box_contents`(내가 보낸 것), `draws` — 모두 BE-02·06·07·10의 읽기 규칙으로 직접 조회

## 만드는 것

- `findMySentBox(sentBoxes, groupId, recipientId)`: 내가 이 그룹에서 이 사람에게 보낸 지정 상자 id 또는 null
- `isUndelivered(draw, myManitoBoxId)`: `draw.undelivered_box_ids`에 내 마니또 상자가 있는지

## 완료 조건

Vitest:
- [ ] `findMySentBox`: 같은 사람이라도 다른 그룹에서 보낸 상자는 찾지 않는다. 마니또 상자는 찾지 않는다.
- [ ] `isUndelivered`: 추첨 전(`draw` null) false, 미전달 목록에 있으면 true

직접 확인:
- [ ] 화면 어디에도 받은 선물 개수가 숫자로 나오지 않는다.
- [ ] 같은 그룹 멤버가 놓은 상자가 받은 사람의 집에 그림으로 보이고, 보낸 사람은 보이지 않는다.
- [ ] 지정 선물을 보낸 집에서는 "이미 선물을 놓았어요 · 수정하기"가 보인다.
