# FE-11 개봉

- 주차: 3주차 (12/7) · 우선순위: P0 (고마워요 답장 P2) · 화면: ⑨
- 근거: 요구사항 9절
- 선행: FE-10, BE-11 · 이 작업을 쓰는 작업: 없음

## 목적

12/25 12:25부터 내가 받은 상자를 하나씩 연다. 마니또는 열 때 보낸 사람이 공개된다.

## 화면과 동작 (⑨, `/groups/:groupId/open`, 멤버만)

- 개봉 시각 전: 잠긴 상자 그림과 "12/25 12:25에 열 수 있어요", 남은 시간(시:분:초).
- 개봉 시각 후
  - 상단: "{그룹 이름} · 받은 선물", 받은 상자들의 겉모습이 한 줄로. 연 상자는 열린 모양.
  - 상자를 누르면 `open_gift` → 내용 카드
    - 마니또: "🎁 마니또는 {닉네임}님이었어요"
    - 지정: "{닉네임}님의 선물"
    - 편지, 사진(서명 URL 1시간, 누르면 크게), 음반(YouTube IFrame Player)
  - 음반 재생을 시작하면 배경 캐롤을 멈추고, 끝나거나 멈추면 다시 켠다(FE-14가 있을 때). 안내 "광고가 나올 수 있어요 · 재생 중에는 캐롤이 멈춰요".
  - **고마워요 답장(P2)**: "고마워요 한 줄 (50자)" 입력 + "보내기". 보낸 뒤에는 내 답장을 보여주고 입력란을 숨긴다.
- 받은 상자가 없으면 "받은 선물이 없어요"와 공개 트리로 가는 버튼.

## 사용하는 백엔드

- `gift_boxes`(내가 받은 겉, `recipient_id = 나`), `rpc('open_gift', { p_box_id })`, Storage `createSignedUrls`, `gift_replies` insert/select (BE-11)

## 예외 처리

- `not_opened_yet` → "12/25 12:25에 열 수 있어요"(시계가 틀린 기기 대비). `not_recipient` → "내 선물이 아니에요". 답장 `23505` → "이미 답장했어요".

## 만드는 것

- `useCountdown(target: Date): { h; m; s; done }`
- `openTitle(kind, nickname): string`
