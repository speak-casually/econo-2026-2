# FE-12 마이페이지

- 주차: 3주차 (12/8) · 우선순위: P0 · 화면: ⑩
- 근거: 요구사항 4.3절
- 선행: FE-03, FE-09, BE-01 · 이 작업을 쓰는 작업: FE-09("내 그룹" 2개 이상일 때)

## 목적

내 프로필, 내 카드, 내 그룹, 알림 설정을 한곳에서 본다.

## 화면과 동작 (⑩, `/me`, 로그인·프로필 필요)

- 프로필: 사진, 닉네임, 로그인 방식("카카오 로그인" / "구글 로그인"), "수정" 버튼 → 닉네임·사진 수정 시트(FE-03의 입력 부품과 검사 재사용).
- 내 카드: 카드 미리보기, "공개 트리에 건 카드", "♥ {좋아요 수}". 누르면 카드 보기. 없으면 "아직 카드를 걸지 않았어요"와 "카드 걸기".
- 내 그룹: 그룹마다 이름, "멤버 {N}명 · 12/25 12:25 개봉". 누르면 그룹 홈. 아래 "+ 그룹 만들기".
- 알림: 토글 "카톡 개봉 알림", 설명 "12/25 12:25 선물이 열렸다고 알려드려요".
  - 켜고 끄면 `user_settings.kakao_notify`를 바로 저장한다.
  - 켰는데 `kakaoMessageConsent === false`이면 카카오 로그인을 다시 실행해 동의 화면을 띄운다.
  - 구글 사용자는 꺼짐·비활성, "카카오 로그인 사용자만 받을 수 있어요".
- 하단: "탈퇴 기능 없음 · 2027-01-31에 모든 데이터가 삭제돼요", "로그아웃".

## 사용하는 백엔드

- `profiles` update(본인), `user_settings` select/update(`kakao_notify`), `tree_cards`(내 카드), `groups` + `group_members` 개수 (BE-01·02·03)

## 완료 조건

직접 확인:
- [ ] 닉네임을 바꾸면 공개 트리와 그룹 홈에 바로 반영된다. 13자는 막힌다.
- [ ] 알림 토글이 새로고침 후에도 유지된다.
- [ ] 그룹 멤버 수는 보이지만 받은 선물 수는 어디에도 없다.

## 범위 밖

- 프로필 신고로 바뀐 닉네임 복구(관리자 기능, BE-13)
