# FE-13 카드 목록

- 주차: 3주차 · 우선순위: P1 · 화면: ④
- 근거: 요구사항 5.4절
- 선행: FE-06, BE-03 · 이 작업을 쓰는 작업: FE-04("전체 보기" 버튼 켜기)

## 목적

트리에 다 걸리지 않는 카드까지 둘러본다.

## 화면과 동작 (④, `/cards`, 비로그인 가능)

- 제목 "전체 카드", 설명 "공개 트리에 걸린 마음 {N}개".
- 정렬 탭: "무작위"(기본), "좋아요순", "최신순".
- 2열 격자. 카드마다 앞면, 작성자 아이콘·닉네임, "♥ {개수}". 누르면 카드 보기.
- 좋아요순·최신순은 20장씩 아래로 스크롤하면 더 불러온다. 무작위는 50장을 한 번에 불러오고 "다시 섞기" 버튼을 둔다.
- 이 작업이 끝나면 홈의 "전체 보기" 버튼을 켠다.

## 사용하는 백엔드

- `tree_cards` + `profiles`(`hidden = false`, `order by like_count desc` 또는 `created_at desc`, `range`), `random_tree_cards(50)` (BE-03)

## 만드는 것 (`api.ts`에 추가)

- `fetchCardsPage(sort: 'likes' | 'latest', page: number, size = 20): Promise<TreeCard[]>`

## 완료 조건

- [ ] Vitest: `pageRange(page, size)`가 `(0, 20)` → `[0, 19]`, `(2, 20)` → `[40, 59]`.
- [ ] 직접 확인: 좋아요순 첫 카드가 좋아요가 가장 많은 카드다. 끝까지 스크롤하면 더 불러오지 않는다. 숨긴 카드는 없다.
