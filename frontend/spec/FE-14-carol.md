# FE-14 배경 캐롤

- 주차: 2주차 (12/6) · 우선순위: P1 · 화면: 모든 화면(🔔)
- 근거: 요구사항 11절, 기술 4.7절
- 선행: FE-01 · 이 작업을 쓰는 작업: FE-11(음반 재생 시 멈춤)

## 목적

사이트 전체에 저작권 문제가 없는 캐롤을 깔고, 사용자가 켜고 끈다.

## 화면과 동작

- 상단 바 🔔 버튼으로 켜기·끄기. 켜져 있으면 버튼이 흔들리는 등 상태가 보인다.
- 처음 방문은 꺼진 상태. 브라우저 자동재생 정책 때문에 사용자가 눌러야 재생된다.
- 켜 둔 상태를 `localStorage`(`carol = on | off`)에 저장한다. 다시 방문했을 때 `on`이면 첫 터치·클릭 때 재생을 시작한다.
- 화면을 옮겨도 끊기지 않는다(`<audio>`를 라우트 바깥 최상위 레이아웃에 둔다).
- 5~10곡을 차례로 반복한다.
- 다른 소리(YouTube 음반)가 재생되면 멈추고, 그 소리가 끝나면 원래 상태로 돌아간다.
- 곡 출처: `public/carols/CREDITS.md`에 곡마다 제목, 연주자, 출처 URL, 라이선스(CC0 / 퍼블릭 도메인 / CC BY)를 적는다. CC BY 곡은 마이페이지 하단 "캐롤 출처" 링크에서 표시한다.

## 만드는 것

- `CarolProvider`, `useCarol(): { on: boolean; playing: boolean; toggle(): void; pauseFor(reason: string): void; resume(reason: string): void }`
- 여러 곳이 동시에 멈춤을 요청해도 모두 `resume`해야 다시 재생한다(멈춤 사유 집합).

## 완료 조건

- [ ] Vitest: 멈춤 사유 집합 로직. `pauseFor('youtube')` 두 번, `resume('youtube')` 한 번 → 재생 재개. `pauseFor('a')`, `pauseFor('b')`, `resume('a')` → 아직 멈춤.
- [ ] 직접 확인(iOS Safari, 안드로이드 Chrome): 🔔를 누르면 재생되고, 화면을 옮겨도 계속된다. 음반을 재생하면 멈추고 끝나면 다시 나온다.
