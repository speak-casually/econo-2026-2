# FE-15 카드 스티커·직접 그리기

- 주차: 3주차 이후 · 우선순위: P1 · 화면: ②
- 근거: 요구사항 5.2절
- 선행: FE-05, BE-15 · 이 작업을 쓰는 작업: 없음

## 목적

공개 카드 앞면을 스티커로 꾸미거나 직접 그린다.

## 화면과 동작 (②의 "앞면" 탭)

- 앞면 탭 안에 "기본 카드" / "직접 그리기" 전환.
- **스티커**: 목록에서 골라 카드 위에 놓고 끌어서 옮긴다. 길게 누르면 삭제. 최대 20개("스티커는 20개까지 붙일 수 있어요"). 위치는 카드 크기에 대한 비율(0~1)로 저장한다.
- **직접 그리기**: 펜 굵기 3단계, 색 8가지, 지우개, 되돌리기. 캔버스 크기는 카드 비율과 같다.
- 저장할 때 그림을 PNG로 만들어 `card-images/{내 id}/{uuid}.png`에 올리고 `drawing_path`에 경로를 넣는다. 수정할 때 새 파일을 올리고 이전 파일은 지운다.
- 카드 보기·트리·목록은 `drawing_path`가 있으면 그림을, 없으면 기본 카드를 보여준다. 스티커는 둘 다 위에 얹는다.

## 사용하는 백엔드

- `tree_cards`의 `stickers`, `drawing_path` (BE-03), Storage `card-images` (BE-15)

## 만드는 것

- `addSticker(list, sticker)`: 20개면 그대로 돌려주고 `full` 표시
- 그리기 기록 `strokes`와 `undo(strokes)`
