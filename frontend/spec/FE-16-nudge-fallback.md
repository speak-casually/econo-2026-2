# FE-16 알림 대체·넛지 배너·링크 미리보기

- 주차: 3주차 (12/9) · 우선순위: P0 · 화면: ⓪, ⑦
- 근거: 요구사항 10절(대체 방안), 계획 12/9 "넛지 배너, 공유, 링크 미리보기"
- 선행: FE-04, FE-09 · 이 작업을 쓰는 작업: 없음

## 목적

카톡 알림을 받지 못하는 사람도 12/25 12:25를 놓치지 않게 하고, 아직 참여하지 않은 사람을 한 번 더 부른다. 카톡으로 공유한 링크가 보기 좋게 보이게 한다.

## 화면과 동작

**캘린더에 추가** (그룹 홈 ⑦, 마이페이지 알림 영역)
- "📅 캘린더에 추가" 버튼이 `.ics` 파일을 내려받게 한다. 일정 "Christmas Gift For You 선물 개봉", 시작 `2026-12-25 12:25 KST`, 30분, 사이트 주소 포함.
- 카톡 알림을 받지 않는 사람(구글 사용자, 토글 꺼짐, 동의 없음)에게는 그룹 홈 상단에 "카톡 알림을 받지 않아요. 캘린더에 추가해 두세요" 배너와 함께 보여준다.

**넛지 배너** (홈 ⓪, 로그인 사용자, 닫으면 그날은 다시 안 보임)
- 카드를 안 걸었으면: "아직 카드를 걸지 않았어요 · 카드 걸기"
- 그룹이 있는데 어느 그룹에도 선물을 안 놓았으면(마감 전): "{그룹 이름}에 아직 선물을 놓지 않았어요"
- 둘 다 해당하면 선물 배너를 먼저 보여준다.
- 개봉 시각 이후: "🎁 선물이 열렸어요! · 열어보기"(그룹이 있을 때).

**링크 미리보기**
- `index.html`에 고정 OG 태그: `og:title` "Christmas Gift For You", `og:description` "12/25 12:25, 함께 여는 크리스마스 선물", `og:image` 1200×630(디자이너 제공). SPA라 초대 링크마다 다른 미리보기는 만들지 않는다.

## 만드는 것

- `buildIcs(siteUrl: string): string`
- `pickNudge(state): 'card' | 'gift' | 'open' | null`

## 완료 조건

Vitest:
- [ ] `buildIcs`에 `DTSTART:20261225T032500Z`, `DTEND:20261225T035500Z`, `SUMMARY:Christmas Gift For You 선물 개봉`이 있다.
- [ ] `pickNudge`: 카드 없음·선물 없음 → `gift`, 카드 없음만 → `card`, 개봉 후 그룹 있음 → `open`, 둘 다 함 → `null`

직접 확인:
- [ ] iOS·안드로이드에서 `.ics`를 열면 캘린더에 일정이 추가된다.
- [ ] 카톡에 사이트 링크를 보내면 제목·설명·이미지가 보인다.
