# FE-17 관리 화면

- 주차: 3주차 · 우선순위: P1
- 근거: 요구사항 5.5·12·13절
- 선행: BE-13 · 이 작업을 쓰는 작업: 없음

## 목적

신고 당번이 SQL 없이 신고를 처리하고, PM이 지표와 그룹 현황을 본다. 추첨 실행은 넣지 않는다(요구사항 8.2절: 대시보드에서 실행).

## 화면과 동작 (`/admin`, 관리자만)

- 관리자 판별: `session.user.app_metadata.role === 'admin'`. 아니면 "페이지를 찾을 수 없어요"(관리 화면이 있다는 것도 드러내지 않는다). 실제 권한은 서버 함수가 다시 확인한다.
- 탭 "신고"
  - 대상별 한 줄: 종류(카드/프로필), 미리보기, 신고 수, 마지막 신고 시각, 현재 상태.
  - 카드: "숨기기" / "숨김 해제". 프로필: "프로필 초기화"(확인 창 "사진을 지우고 닉네임을 '숨김 사용자'로 바꿔요").
- 탭 "현황": 그룹마다 이름, 멤버 수, 상자 수, 마니또 수, 추첨 상태(미추첨 / 수동 / 자동).
- 탭 "지표": `admin_metrics()` 결과를 표로. 지표마다 분모 A·B 두 줄, 비율(%)과 분자/분모.
- 각 탭에 "새로고침".

## 사용하는 백엔드

- `rpc('admin_list_reports' | 'admin_set_card_hidden' | 'admin_reset_profile' | 'admin_group_status' | 'admin_metrics')` (BE-13)

## 예외 처리

- `forbidden` → "관리자만 볼 수 있어요"(역할이 바뀐 직후 등).

## 완료 조건

- [ ] Vitest: `formatRate(2, 3)` → `66.7% (2/3)`, `formatRate(0, 0)` → `- (0/0)`.
- [ ] 직접 확인: 일반 계정으로 `/admin`을 열면 "페이지를 찾을 수 없어요". 관리자 계정으로 카드를 숨기면 다른 계정에서 사라진다.
